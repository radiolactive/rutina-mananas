# Rutina de las mañanas

Guía interactiva en español: 3 ejercicios con una mancuerna, letra grande, botón para escuchar y fotos de forma correcta / incorrecta.

## Cómo abrirla

1. En el celular abre `index.html` (o la URL de GitHub Pages cuando esté activa).
2. Toca **A+** si la letra se ve chica.
3. Toca **Escuchar esta pantalla** para que te lean los pasos.

## Por qué a veces no salen las fotos

Si abres **solo** `index.html` sin la carpeta `p/` (los archivos de las fotos), el navegador muestra un recuadro con un signo de interrogación. Eso es lo que pasó en la captura.

Usa la carpeta completa, o espera a que el sitio de GitHub Pages quede publicado.

## Contenido

- Calentamiento
- Sentadilla a la silla
- Remo a una mano
- Press de hombros sentada
- Hoja semanal (se guarda en el teléfono)
